1. Game Overview

Math Clash is a competitive real-time multiplayer educational game where players improve their mathematical skills by battling opponents in timed matches.

Players are matched against opponents of similar rank. During each battle, both players receive the same math problem simultaneously. The first player to correctly solve the problem earns one point. The match continues until one player reaches five points.

The game is designed to make practicing mathematics engaging through competition while ensuring players continually learn and improve.

4. Experience (XP)

Experience represents overall player progression and is separate from competitive rank.

Players gain XP through:

Winning matches
Losing matches (reduced amount)
Daily challenges
Practice mode
Daily login
Weekly missions

XP increases the player's account level.

Higher account levels unlock:

Avatars
Titles
Borders
Emotes
Achievement badges

XP should never affect gameplay balance. It is purely progression and cosmetic.

11 + 36

...

The same idea applies to algebra:

9. Input System

Players can answer questions using one of two input methods.

Keyboard Mode

Players type the answer directly into an input field.

Recommended for desktop users and lower-level arithmetic.

Handwriting Mode

Players write naturally using:

Mouse
Finger
Stylus
Drawing tablet

A handwriting recognition engine converts strokes into mathematical expressions.

Handwriting recognition supports:

Numbers
Fractions
Square roots
Variables
Mathematical symbols (future release)
Scratch Pad

A separate canvas is provided for rough work.

The scratch pad:

is never graded,
is cleared automatically after each question,
allows students to solve problems naturally.


10. Match Rules
Two players compete.
Both receive the same question.
First correct answer scores one point.
Wrong answers simply clear the player's answer field, allowing another attempt while time remains.
If time expires without a correct answer, the correct solution is shown briefly before the next question.
The first player to reach five points wins the match.
